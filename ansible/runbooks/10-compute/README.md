# Compute Runbooks

Compute runbooks create or manage the machine substrate that higher layers use.

Use this area for:

- bare-metal provisioning
- virtualization platforms such as vSphere and OpenStack
- VM lifecycle operations

Do not put operating system configuration or application deployment workflows
here. Those belong in `30-operating-systems/` and `50-applications/`.

Guides:
